# C57.1 — Observability Integration

Status: remote-first implementation candidate.

This increment extends the C57 observability foundation with gameplay, asset-pipeline, AI/input timing and runtime performance instrumentation while preserving MatchTelemetry v4 and local playtest export fallback.

Remote-first policy remains authoritative: implementation, review and contract validation happen through GitHub branches, pull requests and CI. Local execution is reserved for operations that cannot be completed remotely and must produce deterministic evidence before results are promoted.

C57.1 does not configure a production collector URL and does not claim a Godot runtime bench. Remote transport remains environment/configuration driven.
