# VM02-C19 — Dedicated Riposte Technique Foundation

Tehkné Solutions

## Goal

Convert the validated C18 counter opportunity into a real combat technique instead of leaving it as a timing-only state.

## Contract

- successful parry opens the validated C18 counter/cancel windows;
- consuming the counter arms `ji_riposte` exactly once;
- the next first combo link is promoted to riposte intent;
- riposte has its own damage multiplier, stamina cost and guard pressure;
- only the first connected hit receives riposte amplification;
- dedicated riposte evidence is captured;
- C18 counter/cancel, C17 light/heavy and C16 defense contracts remain intact.

## Visual handoff

C19 establishes the runtime technique contract and temporarily reuses the validated body-hook animation. A later visual pack can replace those frames without changing the `ji_riposte` combat contract.

## Validation

Run `tools/RUN-VM02-C19-DEDICATED-RIPOSTE-GATE.ps1` and return the clipboard report plus both captures.
