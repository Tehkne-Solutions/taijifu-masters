# Responsabilidade de publicação

A implementação, configuração e documentação da versão Web pertencem à Tehkné Solutions.

A conexão inicial da conta Vercel ou Render ao repositório exige acesso administrativo à plataforma de hospedagem. Após essa conexão, os deploys podem ser disparados automaticamente pelos merges na `main`.

Nenhum segredo da conta de hospedagem deve ser salvo no repositório.
