# Sprint 0 — Checkpoint 4: viewport Web

O canvas exportado pelo Godot deve permanecer centralizado no viewport em proporção 16:9.

Contrato:

- `position: fixed`;
- `left: 50%`;
- `top: 50%`;
- `transform: translate(-50%, -50%)`;
- largura e altura limitadas pelo viewport;
- nenhum painel experimental carregado automaticamente.
