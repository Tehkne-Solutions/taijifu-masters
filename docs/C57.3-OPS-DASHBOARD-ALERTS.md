# C57.3 — Operations Dashboard & Alerts

Status: production candidate

## Scope
- collector operational endpoint `/v1/ops`
- dashboard `/dashboard`
- health states: healthy / degraded / critical
- alert rules for runtime errors, frame stalls, asset fallbacks, asset hash mismatches and assembler failures
- environment-configurable thresholds
- remote CI contract

## Default thresholds
- errors: 5
- frame stalls: 8
- asset fallbacks: 3
- asset hash mismatch: 1
- assembler failure: 1

## Environment overrides
- `TAIJIFU_ALERT_ERROR_THRESHOLD`
- `TAIJIFU_ALERT_FRAME_STALL_THRESHOLD`
- `TAIJIFU_ALERT_ASSET_FALLBACK_THRESHOLD`
- `TAIJIFU_ALERT_HASH_MISMATCH_THRESHOLD`

## Operating rule
A critical alert must be correlated with build/deploy identity before promotion of that build. Degraded alerts require investigation when persistent across multiple sessions.

No local repository is required for this milestone.
