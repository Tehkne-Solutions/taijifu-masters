# Primeira release navegável

Esta entrega transforma o projeto Godot em um pacote Web publicável e reproduzível.

## Incluído

- preset Web single-threaded;
- PWA;
- ícone e página offline;
- script de build local/CI;
- validação estrutural de HTML, WASM e PCK;
- teste real no Chromium;
- artefato de build no GitHub Actions;
- configuração Vercel;
- configuração Render Static Site como fallback;
- documentação operacional.

## Não incluído

- conta online;
- sincronização em nuvem;
- multiplayer de rede;
- matchmaking;
- servidor autoritativo;
- publicação automática sem conectar a conta da plataforma de hospedagem.

A URL pública será criada quando o repositório for importado na Vercel ou no Render.
