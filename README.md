# Taijifu Masters

Jogo de luta e plataforma 2D baseado no sistema Taijifu, com combate técnico, preparação estratégica de builds, domínio Tai/Ji/Fu, elementos interativos e arenas móveis.

## Estado

Projeto em fase de Protótipo Zero. O primeiro objetivo é validar o núcleo jogável das **Ruínas do Caminho Triplo** antes da expansão de campanha, multiplayer e conteúdo persistente.

## Tecnologia

- Godot 4
- GDScript
- Arquitetura orientada a recursos
- Primeiro alvo: Windows e Linux

## Princípios do protótipo

- Técnica e leitura permanecem decisivas.
- Builds mudam possibilidades, não garantem vitória.
- Tai, Ji e Fu correspondem a distância, contato e transição.
- Itens de arena geram disputa territorial, não vantagem gratuita.
- Espólios são temporários no núcleo competitivo.
